VALAM PDS - ACTIVE VEHICLE LOAD AND TRIP ROUTE

Apply this update by extracting the ZIP into C:\ValamPDS\src and choosing Replace for the included files.

When a vehicle is on duty, its fleet card now shows:
- remaining load in kilograms compared with vehicle capacity;
- the commodity quantities still being carried;
- each waiting shop stop, its request ID, and the quantities for that shop;
- a View trip route button.

Selecting View trip route opens the Road Map page, highlights the saved route from the warehouse through the planned shop stops, shows the estimated travel time, and lists the goods for every stop.

The route is the dispatch plan stored by the application. This project has no live GPS or vehicle position tracking, so the map does not show the truck's real-time position. Load and stop details update when records refresh and shop receipts are confirmed.
